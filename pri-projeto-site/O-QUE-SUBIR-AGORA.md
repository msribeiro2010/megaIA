## 🚀 OPÇÃO 1: Upload Manual (Mais Rápido)

### Passo a Passo:

1. **Login na Hostinger**
   - https://hpanel.hostinger.com

2. **Gerenciador de Arquivos**
   - Menu → Arquivos → Gerenciador de Arquivos

3. **Navegar até a pasta CSS**
   - Clique em `public_html`
   - Clique em `css`

4. **Upload dos 2 Arquivos**
   - Clique em **Upload**
   - Selecione:
     ```
     ✅ css/style.css
     ✅ css/theme-santalena.css
     ```
   - Confirme **Sobrescrever**

5. **Pronto!** 🎉

⏱️ **Tempo:** 2 minutos

## 🚀 OPÇÃO 2: FileZilla (Recomendado)

## 🆘 Problemas?

### ❌ "Mudanças não aparecem"
**Solução:** Limpar cache do navegador
- iPhone: Safari → ícone AA → Recarregar
- Android: Chrome → Menu → Histórico → Limpar dados

### ❌ "Erro ao fazer upload"
**Solução:** Verificar permissões
- Arquivos devem ter permissão 644
- Pastas devem ter permissão 755
