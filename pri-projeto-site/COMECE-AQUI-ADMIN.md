# 🚀 COMECE AQUI - Editor de Conteúdo Admin

## ⚡ Setup Rápido (3 passos)

### **PASSO 1: Execute o SQL no Supabase** ⭐ **OBRIGATÓRIO**

1. Acesse: https://supabase.com/dashboard
2. Selecione seu projeto
3. Clique em **SQL Editor**
4. Abra o arquivo: `supabase-site-config.sql`
5. Copie **TODO** o conteúdo
6. Cole no SQL Editor
7. Clique em **RUN**

✅ **Sucesso:** Mensagem "Success. No rows returned"

---

### **PASSO 2: Teste o Sistema**

1. Abra no navegador: `teste-admin-conteudo.html`
2. Aguarde 2 segundos
3. Verifique se aparece **4 checks verdes** ✅

**Se aparecer erro vermelho** ❌
- Volte ao PASSO 1
- Execute o SQL novamente

---

### **PASSO 3: Use o Admin**

1. Abra: `admin-login.html`
2. Faça login com suas credenciais
3. Clique em: **📝 Conteúdo do Site**
4. Edite as seções!

---

## ❌ Problemas?

**"Aba Conteúdo não aparece"**
→ Execute o PASSO 1 novamente

**"Erro ao salvar"**
→ Verifique se executou o SQL no Supabase

**"Imagem não carrega"**
→ Execute: `supabase-storage-policies.sql`

**Outros problemas?**
→ Leia: `SOLUCAO-RAPIDA.md`
