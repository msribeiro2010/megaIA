═══════════════════════════════════════════════════════════════════
  FLUXO DE USO DO ADMIN
═══════════════════════════════════════════════════════════════════

1️⃣ SETUP INICIAL (5 minutos)
   → Criar conta Supabase
   → Criar projeto
   → Executar supabase-schema.sql
   → Criar bucket "produtos"
   → Criar usuário admin
   → Configurar credenciais em supabase-config.js

2️⃣ PRIMEIRO ACESSO
   → Abrir admin-login.html
   → Login com credenciais do admin
   → Redireciona para dashboard

3️⃣ ADICIONAR PRODUTO
   → Dashboard → Produtos → Novo Produto
   → Preencher formulário
   → Upload de imagem
   → Salvar
   → ✅ Produto aparece na loja instantaneamente!

4️⃣ EDITAR PRODUTO
   → Produtos → Editar (botão na linha)
   → Modificar dados
   → Upload nova imagem (opcional)
   → Salvar

5️⃣ CONTROLAR ESTOQUE
   → Produtos → Editar
   → Atualizar campo "Estoque"
   → Salvar
   → ✅ Dashboard alerta se estoque ≤5

✅ Row Level Security (RLS)
   - Produtos: público lê, admin modifica
   - Pedidos: apenas dono e admin veem
   - Cupons: validação pública, admin gerencia
   - Storage: público lê, admin envia

   - JWT tokens
   - Sessão persistente
   - Logout seguro
   - Redirecionamento proteção

✅ Validações

   - SQL: prepared statements
