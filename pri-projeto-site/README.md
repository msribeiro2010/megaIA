# Site Priscilla Santalena - Terapeuta Holística

Site profissional para Priscilla Santalena, especialista em terapias holísticas.

## 📋 Estrutura do Projeto

```
pri-projeto-site/
├── index.html              # Página principal
├── produtos.html           # Página de produtos com carrinho
├── css/
│   └── style.css          # Estilos principais
├── js/
│   ├── main.js            # Funcionalidades gerais
│   └── produtos.js        # Sistema de carrinho e filtros
├── images/                # Imagens do site
│   ├── priscilla.jpg      # Foto de perfil
│   └── produtos/          # Imagens dos produtos
└── assets/                # Recursos adicionais

```

## 🌟 Funcionalidades

### Página Principal (index.html)
- ✅ Hero section com call-to-action
- ✅ Seção "Sobre Mim" com informações da terapeuta
- ✅ Seção de Serviços (Essencioterapia, Aromaterapia, Reiki)
- ✅ Depoimentos de clientes
- ✅ Formulário de contato
- ✅ Design responsivo
- ✅ Animações suaves ao scroll
- ✅ Navegação smooth scroll

### Página de Produtos (produtos.html)
- ✅ Sistema de filtros por categoria
- ✅ Carrinho de compras funcional
- ✅ Persistência de dados (localStorage)
- ✅ Contador de itens no carrinho
- ✅ Cálculo automático de totais
- ✅ Notificações ao adicionar produtos
- ✅ Sidebar de carrinho deslizante
- ✅ Badges de destaque (Bestseller, Novo, Oferta)

### Categorias de Produtos
1. **Óleos Essenciais** - Lavanda, Hortelã-Pimenta, Eucalipto
2. **Essências Florais** - Rescue, Mix Menopausa
3. **Difusores** - Cerâmico, Ultrassônico
4. **Kits** - Relaxamento, Menopausa

## 🚀 Como Usar

1. **Abra o projeto**
   ```bash
   cd pri-projeto-site
   ```

2. **Abra no navegador**
   - Abra o arquivo `index.html` diretamente no navegador
   - Ou use um servidor local:
     ```bash
     python3 -m http.server 8000
     ```
   - Acesse: `http://localhost:8000`

3. **Adicione suas imagens**
   - Coloque a foto de perfil em `images/priscilla.jpg`
   - Adicione imagens dos produtos em `images/produtos/`
