🚀 COMO FAZER O DEPLOY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: EXTRAIR ARQUIVOS
   • Extraia este ZIP em uma pasta local
   • Você verá todos os arquivos listados acima

PASSO 2: UPLOAD PARA HOSTINGER
   Opção A - Gerenciador de Arquivos (RECOMENDADO):
      1. Login: https://hpanel.hostinger.com
      2. Arquivos → Gerenciador de Arquivos
      3. Navegue até /public_html
      4. Delete arquivos antigos (se houver)
      5. Upload de TODOS os arquivos/pastas extraídos

   Opção B - FTP (FileZilla):
      1. Configure FTP com credenciais do hPanel
      2. Conecte ao servidor
      3. Arraste arquivos para /public_html

PASSO 3: CONFIGURAR SUPABASE
   1. Crie conta em: https://supabase.com
   2. Crie novo projeto
   3. No SQL Editor, execute OS 4 SCRIPTS (na ordem):
      → supabase-schema.sql
      → supabase-site-config.sql
      → supabase-storage-policies.sql
      → fix-rls-policies.sql

   4. Em Storage, crie 4 buckets PÚBLICOS:
      → hero-images
      → logos
      → about
      → produtos

PASSO 4: ATUALIZAR CREDENCIAIS
   No Gerenciador de Arquivos da Hostinger:
   1. Edite: js/supabase-config.js
   2. Atualize as linhas:
      const SUPABASE_URL = 'https://SEU-PROJETO.supabase.co';
      const SUPABASE_ANON_KEY = 'SUA-CHAVE-AQUI';
   3. Salve o arquivo

PASSO 5: ATIVAR SSL
   1. hPanel → Segurança → SSL
   2. Ative SSL gratuito (Let's Encrypt)

PASSO 6: TESTAR!
   Acesse: https://seudominio.com
   Teste:
   • Página inicial funciona?
   • Produtos aparecem?
   • Admin funciona?

🆘 PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Site não carrega
   → Verifique se arquivos estão em /public_html
   → Não deve estar em /public_html/site/

❌ Imagens não aparecem
   → Upload da pasta images/ completa
   → Verifique permissões (644 para arquivos)

❌ Supabase não conecta
   → Confirme credenciais em js/supabase-config.js
   → Todos os 4 scripts SQL foram executados?
   → Buckets criados como PÚBLICOS?

❌ Admin não funciona
   → Execute: fix-rls-policies.sql no Supabase
   → Teste com: test-supabase.html
